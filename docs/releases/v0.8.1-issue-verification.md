## Public release checks before closing issues

1. Merge only with green GitHub CI.
2. Publish `@aryam/fixmap-core@0.8.1` and `@aryam/fixmap@0.8.1` and verify both `latest` dist-tags.
3. Install the public CLI into a new isolated prefix and run version, help, doctor, MCP help, and a real plan.
4. Verify npm package homepages, tarball contents, integrity, `gitHead`, and the CLI dependency on core 0.8.1.
5. Verify MCP Registry `io.github.aryamthecodebreaker/fixmap@0.8.1`.
6. Verify GitHub tag/release `v0.8.1` and the immutable Action reference.
7. Deploy the website and verify `/`, `/demo`, `/docs`, `/get-started`, and the visible 0.8.1 footer.
8. Close each issue with a link to the release and this ledger only after all checks pass.
