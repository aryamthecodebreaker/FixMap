## Release acceptance

Before tagging, v0.8.8 must pass all of the following from a clean checkout of the release commit:

```text
npm ci
npm run ci
npm run evaluate:external
npm run evaluate:heldout
npm run evaluate:adversarial:gate
npm pack --dry-run --workspace @aryam/fixmap-core
npm pack --dry-run --workspace @aryam/fixmap
```

The release is complete only after the exact merge commit is tagged `v0.8.8`, the publish workflow succeeds, npm and MCP Registry serve 0.8.8, the GitHub release and Action tag resolve to that commit, all 46 issues are closed, and the production website passes the route, metadata, theme, and install-command smoke checks.
