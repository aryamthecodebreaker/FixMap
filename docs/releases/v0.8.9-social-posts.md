## LinkedIn

FixMap v0.8.9 is live.

FixMap is a deterministic, local-first context mapper for coding agents. Give it a task, GitHub issue, or diff and it ranks the files to inspect, routes relevant tests, highlights risk, and explains uncertainty before the first edit.

This release focuses on trust and finish:

- ranking confidence is now independent of the display limit
- Verify and the GitHub Action can fail on advisory warnings when CI needs a stricter gate
- nested workspaces, package-manager conflicts, BOM-less UTF-16, Unicode text, typographic quotes, more languages, and more test conventions are handled correctly
- credentials, Markdown paths, temporary clones, caches, large diffs, comments, outputs, and job summaries are safer
- `/fixmap` without a task lists the complete feature set inside supported coding agents
- CI, publishing metadata, generated artifacts, and recorded evaluations have stronger drift guards
- the website has a calmer, more professional visual system and clearer proof of what FixMap can and cannot do

The release evidence includes full automated tests, cross-platform CI configuration, external and held-out retrieval evaluations, adversarial false-confidence checks, a 1,000-file scan benchmark, packed-package smoke tests, and desktop/mobile browser verification.
