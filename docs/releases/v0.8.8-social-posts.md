## LinkedIn

FixMap v0.8.8 is live—and this release closes the entire 46-issue backlog.

FixMap is a deterministic, local-first context mapper for coding agents. Give it a GitHub issue, task, or diff, and it returns the files to inspect first, reachable test commands, bounded risk notes, and explicit diagnostics before the first edit.

What changed in v0.8.8:

- exact Git-state scan caching for faster Plan, Explain, Compare, Verify, MCP, and Action runs
- shared, version-aware JSON report validation across the CLI, MCP server, and GitHub Action
- more precise diagnostics for unread files, empty diffs, submodules, exclusions, unborn repositories, and Git failures
- safer verification that catches plan/repository mismatches and avoids blaming generated artifacts twice
- broader test recognition for Go, Python, and TypeScript declaration tests
- a real four-stage browser demo powered by FixMap's core engine
- unique metadata, responsive layouts, accessible contrast and focus states, and persistent light/dark mode across the website
- stronger release gates for rendered assets, adversarial cases, external evaluation, clean installs, npm, and the MCP Registry

The release passed 460 automated tests, both external evaluation gates, the adversarial gate, a 1,000-file benchmark, production builds, and browser checks. The evidence page publishes misses and confidence intervals alongside hits.
